CorePOS Community — punto de venta para pymes

Problema: las pymes chilenas necesitan un POS simple, local y asequible, con IVA 19 %, control de caja e inventario, sin depender de la nube.

Solución: aplicación de escritorio para Windows con ventas, caja por turnos, inventario, compras y proveedores, reportes con gráficos, exportación a Excel, usuarios con roles y una API local para usar el celular como escáner de códigos.

Modelo: edición comunitaria open source (MIT) y edición comercial con facturación electrónica SII, licenciamiento e instalador.

  • Lógica de negocio separada de la interfaz (módulos en app/, páginas en app/ui/pages/).
  • Roles y permisos por módulo: ADMIN, VENDEDOR, ENCARGADO_STOCK.
  • API FastAPI con token y CORS cerrado por defecto.
